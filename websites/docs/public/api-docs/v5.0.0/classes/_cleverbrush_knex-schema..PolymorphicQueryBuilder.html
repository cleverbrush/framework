    Class PolymorphicQueryBuilder<S, B, P, Connected>

    Immutable polymorphic read graph. Branches are combined in one PostgreSQL statement; rowSchema is a real discriminated union and variantRowSchemas supplies object schemas for separately configured mappers. Framework does not choose application DTO mappings.
